# Cosmos3-Edge-Policy-DROID

20 denoising steps · Successful trajectory examples

Native and Ours recordings for three tasks:
- Flower arrangement: Pick up a flower from the table and insert it into the vase.
- Book placement: Pick up the book and place it on the bookshelf.
- Plant watering: Pick up the watering can and water the plant.

Each clip starts at the estimated first-chunk inference. Robot-motion events provide approximate alignment between the main video and camera observations. Sparse camera snapshots update at recorded relative timestamps and are held until the next capture. Pause, seek, and playback speed apply to all three views. Paired runs retain their own durations and are not trajectory-normalized.

Open index.html through a static HTTP server. No build, external fonts, analytics, or API keys are needed.
