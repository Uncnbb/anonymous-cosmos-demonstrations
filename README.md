# CosmosPolicy: real-world demonstrations

Anonymous supplementary material with Native and Ours recordings for flower arrangement, book placement, and plant watering.

Open `index.html` or serve this directory with any static HTTP server. All assets use relative paths; no build, external font, analytics, or API key is needed.

## Recording protocol

These are qualitative demonstrations that combine recorded demonstration trajectories with Cosmos-generated residual corrections. Task success was not formally evaluated in the run logs. No success-rate or speedup claim is derived from video duration. Videos retain the supplied timelines, with audio and container metadata removed. Paired runs are not trajectory-aligned. The image explorer shows sparse chunk observations from the wrist and external cameras; the unavailable camera channel is omitted.

## Anonymous website

Import this repository into Anonymous GitHub, select the committed branch, enable the website/Pages option, and use `index.html` at the repository root as the entrance. Set expiration to remove the mirror rather than redirect to the source repository. Share the generated anonymous website URL, not the source GitHub URL.

## Tasks

- Flower arrangement: Pick up a flower from the table and insert it into the vase.
- Book placement: Pick up the book and place it on the bookshelf.
- Plant watering: Pick up the watering can and water the plant.
